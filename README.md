## 🖥️ 서버 명세서

### 1. 게임을 켰다
- 로그인/인증 처리
- 4인 매칭 대기열 등록
- 매치 참가자 목록 및 준비 상태 동기화

### 2. 친구랑 같이 하고 싶다
- 초대 코드/링크 생성 → 같은 방에 배정
- 빈자리는 랜덤 매칭으로 자동 충원
- 파티원 준비 상태 실시간 동기화

### 3. 캐릭터를 골랐다
- 플레이어별 선택 캐릭터 정보 저장
- 동일 캐릭터 중복 선택 가능 여부 판정 (막을 경우 동시 선택 충돌 처리)
- 전원 선택 완료 여부 확인 후 게임 시작 트리거

### 4. 캐릭터를 움직였다
- 방향키 입력을 서버가 검증 후 위치 확정 (서버 권위 모델)
- 대각 이동 시 속도 정규화 처리
- 전원 위치 정보를 매 틱 브로드캐스트

### 5. 아이템을 먹었다
- 획득 판정은 서버가 거리/충돌로 직접 계산 (클라이언트 자가신고 금지)
- 아이템 효과 적용 및 버프 상태 갱신
- 획득된 아이템 제거 및 랜덤 위치 리스폰 관리

### 6. 총알을 발사했다
- 발사 요청 유효성 검증 (쿨다운 등)
- 투사체 생성·이동을 서버가 직접 계산
- 총알 정보를 전원에게 브로드캐스트

### 7. 총알에 맞았다
- 피격 판정을 서버가 직접 계산 (클라이언트 판정 신뢰 안 함)
- 데미지 계산 및 HP 갱신
- HP 0 이하 시 사망 처리 및 탈락 순번 기록

### 8. 60초가 지났다
- 매치 타이머를 서버 절대 시각 기준으로 관리 (클라이언트 타이머는 표시용)
- 시간 종료 시 생존자들의 잔여 HP 비교 후 순위 산정

### 9. 게임이 끝났다
- 최종 순위 결과를 전원에게 동시 전송
- 전적·보상 데이터 갱신
- 매치 리소스 정리 및 재매칭 대기열 복귀 처리
### 맵 (3종)

- **땅이 부서지는 맵** — 시간이 지나며 바닥 타일이 하나씩 파괴되어 낙사 위험이 커진다
- **자기장 맵** — 안전 구역이 시간에 따라 계속 좁아진다
- **총알 난사 맵** — 맵 자체에서 환경 투사체가 날아온다
